# Weather App 🌤️

A simple weather app that fetches real-time weather data for cities around the world.

Built as a certification project for freeCodeCamp's JavaScript Algorithms and Data Structures curriculum.

## Features

- Select a city from the dropdown
- Fetches live weather data from the freeCodeCamp weather proxy API
- Displays temperature, feels like, humidity, wind speed, wind gust, and weather condition
- Shows a weather icon for the current condition
- Handles errors gracefully with a user alert

## Cities Supported

- New York
- Los Angeles
- Chicago
- Paris
- Tokyo
- London

## Tech Stack

- HTML
- CSS
- JavaScript (async/await, fetch API)

## How to Run

1. Clone the repo
2. Open `index.html` in your browser
3. Select a city and click **Get Weather**

## API Used

[freeCodeCamp Weather Proxy](https://weather-proxy.freecodecamp.rocks/api/city/<CITY>)
